# Workspace Project Rules

## Mobile Responsiveness Directive
- Always ensure every feature, UI layout, text overlay, navigation bar, preloader, and canvas component is 100% mobile responsive.
- Test and optimize for small mobile screens (<380px), standard mobile screens (<640px), tablets (<1024px), and desktop displays.
- Use fluid typography (`clamp()`), flex/grid wrapping, touch-friendly tap targets (minimum 44x44px), and appropriate padding/margins on mobile viewports.
